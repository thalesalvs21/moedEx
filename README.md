# MoedEx
 
> 🚧 Projeto em desenvolvimento
 
Conversor de moedas web com cotações em tempo real. Escolha a moeda de origem, a moeda de destino e o valor, e o MoedEx faz a conversão usando dados atualizados da [AwesomeAPI](https://docs.awesomeapi.com.br/api-de-moedas).
 
O nome vem de **Moed**a + **Ex**change (câmbio em inglês).
 
## Funcionalidades
 
- [x] Interface com seleção de moeda de origem e destino
- [ ] Botão para inverter as moedas
- [ ] Conversão com cotação em tempo real
- [ ] Conversão entre quaisquer moedas usando o real como ponte
- [ ] Tratamento de erros (sem internet, API fora do ar, valor inválido)
- [ ] Gráfico com o histórico da cotação
- [ ] Suporte às 20 moedas mais relevantes
## Tecnologias
 
- HTML
- CSS
- JavaScript
- [AwesomeAPI](https://docs.awesomeapi.com.br/api-de-moedas) — API pública de cotações
## Como rodar
 
1. Clone o repositório:
```bash
   git clone https://github.com/thalesalvs21/moedex.git
```
2. Abra o arquivo `index.html` no navegador.
Não precisa instalar nada.
 
## Objetivo
 
Projeto de portfólio criado para aprender JavaScript e consumo de APIs na prática: requisições com `fetch`, `async/await`, manipulação do DOM e tratamento de erros.
